# betgirl-anchor

[betgirl.site](https://betgirl.site) 공개 베팅 장부의 **해시 체인 앵커 저장소**.

betgirl 원장(베팅·정산)은 행마다 `SHA-256(직전 행 해시 + 정규화 원문)` 체인으로 봉인된다.
이 저장소에는 매일 그 체인의 tip 해시와 행 개수가 기록된다 (`anchors.jsonl`).

- 원장을 사후에 조작하면 체인이 여기 기록된 tip 과 어긋난다.
- 원장을 통째로 재구축해도 이 저장소의 커밋 히스토리와 어긋난다.
- 앵커 레코드끼리도 sha256 으로 연결되어 중간 삭제가 드러난다.
- `ots/` 의 `.ots` 파일은 OpenTimestamps(비트코인 체인) 증명 — 운영자도 위조할 수 없는 타임스탬프.

검증: betgirl.site/ledger 의 "무결성 검증"이 이 저장소의 최신 앵커와 자동 대조한다.
수동 검증도 가능 — 원장 전체를 내려받아 체인을 재계산한 뒤 여기 기록된 tip 과 비교하면 된다.
